# skills
My own skills for AI agents

Some of these skills are from [mattpocock/skills](https://github.com/mattpocock/skills), with some customization to make them works better for me. 

## Why customize

- [@mattpocock](https://github.com/mattpocock) is mainly a frontend developer, but what I am doing is with more diversification.
- I have a little bit different workflow with him. For example, I prefer to make things work in local filesystem instead of using things like GitHub/GitLab, of course his skills also support this, but with cost of tokens and models' consentration (which local LLMs lack).
- I can't afford to pay several hundred dollars to LLM providers (My living costs are less than $200 a month, excluding rent!). Instead, I use local LLMs like QWen3.6-35B-A3B and QWen3.6-27B for my personal use. They work, but they are much less clever than Claude Fable or GPT-5.6. So they need skills a little bit more "direct" to follow.
